## `01` — WHO AM I?

> **YukakooNeko** is a personal space for experiments, projects, automation, research, and ideas that start as *"what if..."* and end up becoming something real.

I enjoy building things around **JavaScript / Node.js**, exploring **OSINT**, working with databases, and turning simple web ideas into usable systems.
